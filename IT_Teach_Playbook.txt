==================================================
KAISE SAMJHAO (ye order)
==================================================

1. MISAAL (pehli 2-3 lines)
   Path param = ghar ka number. Bina number ke postman ghar nahi dhundhega.
   Query param = extra baat: "shaam ko aana, lift se aana". Optional.

2. SEEDHI BAAT
   Path = kaun si cheez. Query = us cheez ko kaise filter/sort/dikhana hai.

3. EK URL
   /products/7?currency=INR
   7 = kaun sa product (path)
   currency=INR = kaise dikhao (query)

4. TABLE (sirf vs sawal pe)
   Aspect | Path | Query
   Kahan | /users/42 | /users?role=admin
   Kaam | ID / naam | filter, sort, page
   Zaroori | zyada tar haan | nahi

5. CODE - dono languages, chhota, chalane layak

6. GALTI
   Filter ko path mein mat daalo (/users/admin/sort/name). Route toot jaate hain.

7. YAAD
   Path = WHAT (kaun). Query = HOW (kaise filter).

Pehle analogy, baad mein code. Lamba lecture mat likho.

GOLD EXAMPLE - aise jawab do
==================================================

Sawal: Params vs Query Params define

Jawab (style copy karo):

Socho ek dukaan.

Path param = shop ka exact stall: Shop No. 7.
Bina iske pata nahi kis dukaan pe jaana hai.

Query param = extra request: "red shirt dikhao, saste se mehnga sort karo".
Ye optional hai. Na bolo to bhi dukaan mil jaati hai.

URL:
GET /products/7?currency=INR
- 7 path hai (kaun sa product)
- currency=INR query hai (kaise price dikhao)

Aspect | Path params | Query params
Jagah | /products/7 | /products?sort=price
Matlab | kaun si cheez | filter / sort / page
Zaroori | haan | nahi
Example | /users/42 | /users?q=ram&page=2

JavaScript (Express):

```javascript
import express from "express";
const app = express();

// /users/42  ->  params.id = "42"
app.get("/users/:id", (req, res) => {
  res.json({ userId: req.params.id });
});

// /users?role=admin&sort=name  ->  query
app.get("/users", (req, res) => {
  const role = req.query.role;
  const sort = req.query.sort || "id";
  res.json({ role, sort });
});

// dono saath: /products/7?currency=INR
app.get("/products/:id", (req, res) => {
  res.json({
    productId: req.params.id,
    currency: req.query.currency || "INR",
  });
});
```

Python (FastAPI):

```python
from fastapi import FastAPI, Query
app = FastAPI()

@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"userId": user_id}

@app.get("/users")
def list_users(role: str | None = None, sort: str = "id"):
    return {"role": role, "sort": sort}

@app.get("/products/{product_id}")
def get_product(product_id: int, currency: str = Query("INR")):
    return {"productId": product_id, "currency": currency}
```

Galti: /users/admin/sort/name mat banao. ID path mein, filter query mein.

Yaad rakho: path = kaun, query = kaise chhanto. Interview mein yahi ek line bolna.
